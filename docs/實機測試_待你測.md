# 實機測試：要你親手測的（1.0.0）

我能測的都測完了（見文末）。剩下的都要**真的用滑鼠右鍵**、改遊戲設定，或需要這台電腦沒有的東西，只能由你測。

準備：

- 世界列表裡的「Herbal 1.1 Test」就是豐收的測試世界（資料夾 `HarvestTest01=`），開了作弊，平台在 (52–63, 119, −58–−46)。上面已經擺好 21 樣食物、榨汁機和醃漬缸。
- 拿東西：`/give @s kaleidoscope_harvest:<物品> <數量>`。
- 生存模式測吃東西：`/gamemode survival`，先 `/effect @s hunger 30 255` 把飽食度降下來。
- 結果欄填 ✅ / ❌，❌ 請寫看到什麼（截圖更好）。
