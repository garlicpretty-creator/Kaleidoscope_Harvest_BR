## 和《森羅物語：酒館》的葡萄互通

兩包都裝時，豐收的葡萄和酒館的葡萄（`kaleidoscope_tavern:grape`）可以互相代用。沒裝酒館時什麼都不會送，豐收照常玩。

| 方向 | 怎麼做到 |
| --- | --- |
| 豐收葡萄 → 酒館壓榨桶 | 用酒館 SDK 登記壓榨桶配方 `kaleidoscope_harvest:pressing/grape`（需要 `pressing_recipes`），壓出**酒館自己的**葡萄汁，每顆 125 mB，和酒館葡萄一樣；之後照酒館的流程釀葡萄酒。豐收不做自己的葡萄酒 |
| 酒館葡萄 → 豐收榨汁機 | 算作葡萄：兩顆，或和豐收葡萄各一顆，都裝出豐收的葡萄汁；空手取回時拿到的還是酒館葡萄 |
| 酒館葡萄 → 廚房竹篩 | 多登記一道曬葡萄乾的配方；先用 `ItemTypes` 確認酒館葡萄存在才送 |

合成台的葡萄乾麵包、水果拼盤仍只收豐收的葡萄：合成配方寫進酒館的物品，沒裝酒館的玩家會看到報錯。兩邊的葡萄藤苗也不互通。

已知差異：豐收葡萄在壓榨桶裡壓時有聲音，但沒有果汁噴濺粒子。酒館只讓登記了家具的擴充提供壓汁粒子。
