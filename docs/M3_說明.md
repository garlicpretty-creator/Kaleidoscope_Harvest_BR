# M3 說明：水果與果樹

M3 加入 5 種水果與其餘 10 種果樹，並把美術 PR 的作物、果樹貼圖接上。完成後企劃書的 35 種作物全部到齊：24 種田間作物（12 蔬菜、7 香料、5 水果）加 11 種果樹。開發流程見 [M1 說明](M1_說明.md)。

## 水果

| 水果 | 型態 | 氣候 | 怎麼種 | 第一份來源 |
| --- | --- | --- | --- | --- |
| 草莓 | 可重複採收 | 溫和 | 草莓苗 | 繁花森林野生 |
| 藍莓 | 灌木（新型態） | 寒冷 | 藍莓苗，種在草地或泥土上 | 針葉林野生 |
| 葡萄 | 藤架 | 溫和 | 葡萄藤苗點竹藤架 | 平原、針葉林村莊箱子；森林野生 |
| 百香果 | 藤架 | 炎熱 | 種子點竹藤架 | 叢林野生 |
| 鳳梨 | 原株再生 | 炎熱 | 鳳梨冠芽 | 熱帶草原野生 |

- **灌木**：藍莓種在草地、泥土（耕地也可以），熟了點它採收，退回第 4 階段再結果。
- **鳳梨「一次性，原株再生」**：熟了點它得到 1 顆鳳梨，植株退回第 2 階段重新長，不用重種，但要等比較久。

果樹照企劃書「果樹生長」（美術 PR #4 改過的版本）：

- **方塊**：樹葉 `kaleidoscope_harvest:<果樹>_leaves`，樹幹 `fruitwood_log`（香蕉是 `banana_trunk`），垂掛果實 `<果樹>_fruit`（肉桂以外 10 種），樹苗 `<果樹>_sapling`。
- **長成**：樹苗 4 階段後，腳本在樹苗的位置呼叫 `dimension.placeFeature("kaleidoscope_harvest:<果樹>_tree_feature", 位置)`，樹形由 `features/trees/`（`tools/art/tree_shapes.py`）決定，每棵樹會隨機變化。放不下（空間不夠、地面不對）時樹苗留在最後一階段，之後的 random tick 再試。
- **野外**：整棵樹由 `feature_rules/trees/` 生成；另外也會生成少量野生樹苗（`features/wild`、`feature_rules/wild` 的 `wild_<果樹>_sapling_*`，每區塊 6%，比野生作物的 15% 少），可以挖回家種。柑橘都沒有，只從村莊樹苗取得。樹葉偶爾掉樹苗（5%）也是取得方法。
- **樹葉兩階段**：無花 → 開花，tree_feature 生出來的是預設的無花。開花的樹葉下方是空氣時，會在下方生出一顆小青果，樹葉回到無花；下方不是空氣就一直開著花等。只有樹冠最下面一層、底下空著的樹葉會結果。
- **垂掛果實**：小青果 → 大青果 → 熟果（方塊狀態 `growth` 0–2，模型骨骼 `stage0`～`stage2`），照果樹的氣候與溫室規則長，偏離氣候就停在原階段。點熟果：掉下水果（數量照 `pick`）、果實方塊消失，有摘取音效與粒子，不跳文字。沒熟前點它沒反應；骨粉一次推進一階段。
- **果實掉落規則（自訂）**：果實只能掛在自己果樹的樹葉正下方（`placement_filter` 朝下、只認那種樹葉）。上方樹葉沒了（被打掉、腐爛、爆炸）果實就掉下來：**熟果照樣掉水果，青果什麼都不掉**；直接打掉果實也是同樣規則。遊戲的 `placement_filter` 會處理，腳本在樹葉被打掉、腐爛與果實的 random tick 也會檢查一次。
- **肉桂（剝皮）**：肉桂沒有果實方塊。它的「開花」是一叢紅褐色嫩葉；嫩葉長出來時點樹葉，剝下一片肉桂皮，樹葉回到無花，之後會再長。樹幹仍是共用的果木原木，所以剝皮做在肉桂自己的樹葉上。
- **樹幹砍掉**：樹葉在 4 格內找不到樹幹就在下次 random tick 掉落（由近到遠找，找到就停），掛在下面的果實一起掉。
- **骨粉**：樹苗一次一階段；無花的樹葉 → 開花；開花的樹葉 → 下方空著就結一顆小青果。
- 全部只靠 random tick 與玩家互動，不每 tick 掃描：樹葉只看正下方，果實只看正上方。

**G3 關卡（果樹可重複採收，存檔重載後狀態正確）**：果樹的所有狀態（樹苗階段、樹葉 `blossom`、果實 `growth`、是否偏離氣候）都存在方塊狀態裡，腳本沒有放在記憶體的資料，所以重載後不會遺失。重載這一點要進遊戲確認。

## 美術接上

- 作物方塊用美術的模型 `geometry.kaleidoscope_harvest.<作物>_crop`（「#」字或交叉形，灌木藍莓也是）：骨骼 `stage0`～`stage3`，每個 permutation 用 `bone_visibility` 只顯示目前階段；材質實例 `stage0`～`stage3` 指到 `crops/<作物>_stage_N`。方塊狀態 0–7 對應階段 `floor(狀態 / 2)`（docs/art/CROP_TEXTURES.md）。
- 玉米上半格用 `geometry.kaleidoscope_harvest.corn_upper`（骨骼 `stage2`、`stage3`，貼圖 `corn_upper_stage_2/3`）。
- 藤架作物用各自的 `geometry.kaleidoscope_harvest.bamboo_trellis_<藤蔓>`：`trellis` 材質是竹藤架貼圖，`stage0`～`stage3` 是藤蔓各階段。單獨的竹藤架仍用 `bamboo_trellis` 模型，藤蔓透明。
- 樹苗用 `geometry.kaleidoscope_harvest.sapling`（材質實例 `sapling` → `saplings/<果樹>_sapling`）。
- 樹葉用 `trees/<果樹>_leaves_bare/blossom`；垂掛果實用 `geometry.kaleidoscope_harvest.<果樹>_fruit`（`models/blocks/<果樹>_fruit.geo.json`），貼圖 `blocks/fruit/<果樹>_fruit`（附 normal／MER 與 texture set），`alpha_test`、沒有碰撞、選取框照模型大小。樹幹用 `fruitwood_log`（側面、年輪）與 `banana_trunk`。
- 野生作物用該作物模型的成熟階段（`stage3`）；野生藤蔓沒有竹架，仍用十字平面。
- **偏離氣候的灰葉**：美術沒有畫灰色版，生成器讀美術貼圖、降低飽和度後另存一份，normal／MER 圖一起複製。
- **PBR**：美術附的 `_normal`、`_mer` 圖現在都有 `texture_set.json`，RP manifest 加上 `"capabilities": ["pbr"]`。
- 方塊貼圖全部改用美術。程式畫的佔位圖已全部移除：還沒畫的 icon 不再補佔位圖，而是照美術的路徑命名、列在 `docs/art/MISSING_ART.md`，畫好放上去就生效。
- icon 已齊全（`docs/art/MISSING_ART.md` 為空）；樹葉與樹幹的 icon 由 `tools/art/block_icons.py` 畫成等角方塊，pack icon 用柳橙、葡萄、大白菜、玉米四個 icon 組成。

## 與美術 PR #4 的差異（已處理）

M3 寫完後，main 合併了美術 PR #4，並改了企劃書的「果樹生長」。下表的差異都已改成企劃書與美術的做法（`fix/align-art`）：

| 項目 | 原本程式（M3） | 現在（對齊企劃書與美術 PR #4） | 狀態 |
| --- | --- | --- | --- |
| 樹形 | 腳本放固定形狀（一般 3＋21、香蕉 4＋9） | `features/trees/` 的 `tree_feature`，樹苗用 `placeFeature` 長成；放不下就保留樹苗晚點再試 | 完成 |
| 果實 | 果葉方塊的 `fruit_stage` 四階段 | 樹葉兩階段（無花／開花）＋垂掛果實方塊 `<果樹>_fruit`（小青果 → 大青果 → 熟果） | 完成 |
| 方塊 ID | `<果樹>_fruit_leaves`、`fruit_log` | `<果樹>_leaves`、`fruitwood_log`（`banana_trunk` 不變） | 完成 |
| 野外 | 世界生成野生樹苗 | `feature_rules/trees/` 直接生成整棵樹，並保留少量野生樹苗 | 完成 |
| 作物模型 | 十字平面、竹藤架單一模型 | `<作物>_crop`、`corn_upper`、`bamboo_trellis_<藤蔓>`、`sapling` 模型，`bone_visibility` 切換階段 | 完成 |

- `npm run validate` 現在會檢查世界生成用到的方塊 ID 都存在（以前是警告，現在是錯誤），也檢查方塊用到的模型、骨骼與材質實例都在 RP 的模型裡。
- 舊存檔裡 M3 版的 `fruit_leaves`、`fruit_log` 方塊會變成未知方塊；還沒發佈過，所以不做轉換。

## 需要進遊戲確認

- `bone_visibility` 寫在 permutation 裡切換作物、藤架、果實的階段骨骼。
- 垂掛果實的 `placement_filter`（`allowed_faces: ["down"]`、只認自己的樹葉）：上方樹葉消失時會不會掉、熟果被擠掉時是否照 loot 掉水果。
- `dimension.placeFeature` 在樹苗位置長樹（樹苗列在 `may_replace`），放不下時回傳 `false`。
- 樹冠較大的樹（梨的分枝、荔枝、芒果）最外圈樹葉離樹幹是否都在 4 格內，不會自己掉。
- PBR 貼圖組在開光影時的效果。
- 灌木的 `placement_filter` 接受草地與泥土。
- 竹林（八角）、叢林邊緣（肉桂）的野生樹是否生得出來（docs/art/TREE_SHAPES.md）。
- 重新進入世界後，果樹、果實與作物的狀態都還在（G3）。
