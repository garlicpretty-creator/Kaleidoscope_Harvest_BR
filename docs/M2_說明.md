# M2 說明：蔬菜與香料

M2 補齊企劃書的 12 種蔬菜與 7 種香料（M1 已有大白菜、蔥、玉米、小黃瓜，本次新增 15 種），加上砧板、石磨配方與野生作物的世界生成。開發流程與 M1 相同，見 [M1 說明](M1_說明.md)。

## 野生作物

- 每種作物有一個不會生長的「野生」方塊，打下來得到作物，種子作物另外給種子。
- 世界生成照草本的野生藥草寫法：`feature_rules/wild/` 每個生物群系標籤一條規則 → `search_feature` 往下找地表 → `single_block_feature` 放方塊。
- 密度：每個區塊每種作物試 1 次、機率 15%（`tools/generate.mjs` 的 `WILD_SPREAD`）。平原同時有 8 種作物，大約每個區塊 1 株，要在遊戲裡看實際感覺再調。
- 只會出現在新生成的區塊。

## 配方

| 器具 | 配方 |
| --- | --- |
| 砧板 | 蔥→蔥花、大蒜→蒜末、薑→薑絲、香菜→香菜末、洋蔥→洋蔥丁、白蘿蔔→蘿蔔塊、小黃瓜→拍黃瓜 |
| 石磨 | 芝麻→芝麻粉＋芝麻油（50%）、花生→花生油（50%）、大豆→豆漿＋豆渣、黑胡椒→黑胡椒粉、孜然→孜然粉 |
| 炒鍋 | 蔥花炒蛋、蒜炒青菜、蒜炒菠菜、洋蔥炒蛋、紅燒茄子 |
| 湯鍋 | 白菜燉肉、橘子糖水、蘿蔔燉牛腩 |
| 蒸籠 | 蒸玉米、蒸地瓜、蒸芋頭 |

石磨 payload 照草本 1.2 的格式：`{ input, outputs: [{ id, count, chance }] }`。每個 M2 作物都至少有一個用途（驗證工具會檢查）；完整菜單與「每種至少兩個用途」的 G4 關卡在 M4。

## 和企劃書不同、需要你決定的地方

1. **洋蔥、地瓜的「村莊箱子」來源**：基岩版要往村莊箱子加東西，只能覆寫原版的 `loot_tables/chests/village/*.json`，這會蓋掉原版內容，也會和其他改同一張表的附加包互相覆蓋。M2 先讓它們也在野外生長（洋蔥在平原、地瓜在熱帶草原），這樣 G2 關卡成立。要不要另外覆寫村莊箱子，請你決定。
2. **芝麻油、花生油目前是一般物品**：要當廚房炒鍋用油得註冊油品容器，物品必須改成不可堆疊並帶油量屬性，排在 M4 和榨汁機、醃漬缸一起做（企劃書原本也排在 M4）。
3. **茶壺配方（薑母茶）**：草本的茶是用廚房空杯盛裝、可放置的方塊食物，牽涉較多，排到 M3／M4 與果茶一起做。

## 需要進遊戲確認

- 生物群系標籤 `swamp`、`desert` 是否如預期（草本只驗證過 plains、forest、flower_forest、savanna、jungle、taiga 等）。
- 野生作物的密度與出現位置。
- M1 清單中尚未確認的項目仍然有效。
