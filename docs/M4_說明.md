# M4 說明：料理與新器具

M4 加入榨汁機、醃漬缸、整份菜單（料理、飲品、中間食材）、植物油容器與手冊章節的新分類。M3（水果與果樹）由另一支程式同時撰寫，所以 M4 的水果相關內容先寫好、等 M3 的物品出現才啟用（見「與 M3 的銜接」）。開發流程見 [M1 說明](M1_說明.md)。

## 菜單

全部寫在 `packs/BP/scripts/data/menu.js`，一列一樣東西：物品本身加上做法。物品 ID 照美術資產 `tools/art/icon_prompts.json` 的命名，所以畫好的 icon 直接套上。

| | 現在可用 | M3 加入後 |
| --- | --- | --- |
| 料理 | 29 | 44 |
| 飲品 | 2（橘子汁、薑母茶） | 8 |
| 中間食材 | 21 | 27 |

企劃書目標是 40 道料理加 20 種中間食材，M3 的水果加入後兩項都達到。

做法涵蓋所有器具：

| 器具 | 誰處理 | 例子 |
| --- | --- | --- |
| 砧板、石磨、炒鍋、湯鍋、蒸籠 | 廚房 API | 蒜末、花生醬、宮保雞丁、玉米濃湯、芋泥 |
| 茶壺 | 廚房 API（草本的格式） | 薑母茶、檸檬茶、百香果茶，倒進廚房的杯子 |
| 竹篩 | 廚房 API（草本的格式） | 陳皮、柿餅、葡萄乾 |
| 榨汁機 | 豐收 | 橘子汁、柳橙汁、葡萄汁、芒果汁、綜合果汁 |
| 醃漬缸 | 豐收 | 醃白菜、泡菜、醃蘿蔔、醃黃瓜、醬油、三種果醬 |
| 工作台、熔爐 | 原版配方 | 蔥油餅、胡椒餅、藍莓派、烤地瓜 |

吃完會還回容器：用碗盛的料理還碗、果汁還玻璃瓶、茶還廚房空杯。

## 新器具

**榨汁機**（木板、玻璃、鐵錠合成）
- 拿水果點它放進去，最多兩顆。裝滿後拿空玻璃瓶點它，掉出一瓶果汁。
- 兩顆同樣的水果榨出那種果汁，兩顆不同的榨出綜合果汁（至少有兩種可榨的水果時才啟用）。
- 壺裡的顏色跟著第一顆水果變（橘、紫、黃三色）。空手點它把水果拿回來，打掉也會還水果。

**醃漬缸**（木板、黏土球合成）
- 拿食材點它放進去，最多四樣，不分順序。缸裡剛好是一道配方時，空手點它封缸。
- 缸口顏色：新鮮 → 發酵中 → 完成（紅褐色）。完成後空手點它開缸取出。
- 計時用世界時間（`world.getAbsoluteTime()`），玩家不在附近也會繼續。醃菜 1 天、果醬半天、醬油 3 天。
- 材料對不上任何配方時，空手點它把東西還回來。打掉時無論有沒有封缸都退回材料。

兩個器具的內容物都記在世界動態屬性裡（`utils/blockStore.js`），不做每 tick 掃描。模型與狀態貼圖用美術 PR 的 `juicer.geo.json`、`pickling_jar.geo.json`。

## 植物油

芝麻油、花生油照樂牧豬油的格式用 `register_oil_container` 註冊成炒鍋用油，容量 256 次，用完留下空瓶。為此兩種油改成不可堆疊。

## G4 關卡：每種作物至少兩個用途

`npm run validate` 會檢查：每種作物和水果，順著中間食材追下去（大蒜 → 蒜末 → 三道菜），至少要能變成兩樣可以吃喝的東西（料理、飲品、醃漬品、果醬或油）。現有 19 種作物加柑橘都通過。為了讓香菜和孜然過關，新增了孜然馬鈴薯，酸菜麵也加了香菜末。

## 與 M3 的銜接

- 水果相關的 27 列（果汁、果茶、果醬、柿餅、葡萄乾、五香粉、15 道水果料理）寫在菜單裡，但只要任何一項豐收材料還不存在，那一列就完全不出現：沒有物品、配方、手冊條目。M3 的物品一加進 `data/items.js`，這些列就自動啟用。
- 它們等的 ID 照美術命名：`strawberry`、`blueberry`、`grape`、`passion_fruit`、`pineapple`、`sweet_orange`、`lemon`、`peach`、`pear`、`persimmon`、`lychee`、`mango`、`banana`、`star_anise`、`cinnamon_bark`。**如果 M3 用了不同的 ID，請改 M3 或改 `menu.js`，兩邊對上就好。**
- 有一項測試會檢查「這 15 個 ID 都存在時，整份菜單全部啟用」。
- 我把 `main` 合併進了這個分支（美術 PR），M4 才用得到器具模型。M3 那邊合併時可能會在 `data/items.js`、`tools/generate.mjs` 碰到衝突；M4 盡量把內容放在新檔案（`menu.js`、`stations.js`、`stations/`）以減少衝突。

## 其他變更

- 中間食材與料理從 `items.js`、`dishes.js` 搬到 `menu.js`；`dishes.js` 現在只把啟用中的菜單列轉成配方。
- 改名以對齊美術：`ginger_shreds` → `shredded_ginger`、`napa_cabbage_pork_stew` → `cabbage_pork_stew`、`daikon_beef_stew` → `daikon_beef_brisket`；`garlic_spinach` 換成 `spinach_salad`（涼拌菠菜），`steamed_taro` 換成 `taro_paste`（芋泥）。
- 美術有畫的物品 icon 直接使用（81 個物品中 68 個），其餘仍是佔位圖。
- 中間食材改放廚房的 `ingredients` 創造模式分組，飲品放 `tea_drinks`，器具放 `cooking_stations`（草本用過這三個分組 ID）。
- 修正生成器會刪掉 `RP/models/blocks` 裡手做模型的問題。

## 尚未處理

- **作物 ID 與美術不一致**：香菜（程式 `cilantro`，美術 `coriander`）、黑胡椒（程式 `black_pepper`，美術 `black_peppercorns` 加 `black_pepper_seedling` 藤苗）、蔥（美術有 `scallion_seeds`，程式用蔥本身種）。M3 也在改作物相關檔案，等 M3 合併後再統一改名，比較不會衝突。
- **美術的作物貼圖**（4 階段加 normal／MER）還沒接上，方塊仍用程式畫的 8 階段佔位圖。這和改名一起做比較好。
- 白米相關料理（地瓜粥、滷肉飯、鳳梨炒飯、芒果糯米飯）需要廚房的米 ID，確認前先不做。
- 蒜蓉蒸茄子：廚房蒸籠一次只收一樣材料，做不出「茄子加蒜」，先不做。

## 需要進遊戲確認

- 茶壺、竹篩、油品容器的 payload 是照草本和樂牧抄的，要確認廚房真的收下。
- 茶要用廚房空杯取出是否正常；飲品沒做成可放置的方塊，和草本不同。
- 新音效 ID：`block.composter.fill`、`bucket.fill.water`、`block.barrel.open/close`、`block.composter.ready`。
- 榨汁機玻璃壺的 `blend` 材質、醃漬缸空缸時缸口是否透明。
- 器具方塊的碰撞箱大小。
