# 實機測試：1.1 要你測的

1.1 的新內容只用模擬的 `@minecraft/server` 測過（`npm test` 92 項），下面這些要進遊戲才知道。1.0 的待測清單（[實機測試：要你親手測的](實機測試_待你測.md)）還沒測的項目也一併測。

準備：

- 匯入 `dist/Kaleidoscope-Harvest-v1.1.0.mcaddon`，開新世界（世界生成只出現在新區塊），開作弊，掛上豐收和廚房。
- 打開內容記錄（設定 → 創作者 → 內容記錄 GUI），留意 `kaleidoscope_harvest` 的錯誤或警告。
- 拿東西：`/give @s kaleidoscope_harvest:<物品>`；加快生長：`/gamerule randomtickspeed 300`（測完改回 `1`）。
- 結果欄填 ✅ / ❌ / ⚠️，❌ 和 ⚠️ 請寫看到什麼。

## 1. 水生作物（最優先：企劃書風險表第一列）

| # | 步驟 | 預期 | 結果 |
| --- | --- | --- | --- |
| 1.1 | 挖一格深的坑，底下放泥巴，倒水；拿蓮藕對水底點 | 蓮藕種進水裡，水還在（方塊含水），沒有被沖掉 | |
| 1.2 | 等它長 | 8 個階段長大；成熟時頂端開粉紅荷花 | |
| 1.3 | 打下成熟的蓮藕 | 掉蓮藕，有時多一個蓮蓬 | |
| 1.4 | 把水舀掉 | 作物變灰、不再長；倒回水後恢復 | |
| 1.5 | 拿空心菜種子種在廚房水田上 | 種得下、會長 | |
| 1.6 | 拿茭白筍種在原版耕地上（沒有水） | 種不下去 | |
| 1.7 | 空手點成熟的空心菜、茭白筍 | 掉作物，退回前幾個階段繼續長 | |
| 1.8 | 新沼澤、河邊、紅樹林沼澤的淺水 | 找得到野生蓮藕、茭白筍、空心菜，是泡在水裡的 | |
| 1.9 | 水流過來沖到一般作物和水生作物 | 一般作物照原版被沖掉；水生作物留著 | |

若 1.1 失敗（點下去沒反應，或放下後水不見了）：把內容記錄截圖給我。退路是水生作物只能種在廚房水田上。
