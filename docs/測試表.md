# 遊戲內測試表（1.0.0）

自動測試（`npm test` 65 項）用的是模擬的 `@minecraft/server`，下面這些只有進遊戲才測得出來。每一項的來源是各里程碑說明的「需要進遊戲確認」，加上整體的種植、料理流程。

**填法**：「結果」欄填 ✅ 正常、❌ 壞了、⚠️ 能用但怪怪的、— 沒測；❌ 和 ⚠️ 請在「備註」寫看到什麼（最好附截圖或內容記錄那一行）。**優先**欄的 P0 是最可能出問題、要先測的。

### 開測前

1. 開一個**新世界**（世界生成只出現在新區塊），開作弊，行為包與資源包都掛上豐收和廚房。
2. 打開內容記錄：設定 → 創作者 → 開啟「內容記錄 GUI」，等級選「警告」以上。整場測試都留意有沒有 `kaleidoscope_harvest` 的錯誤或警告。
3. 好用的指令：
    - 加快生長：`/gamerule randomtickspeed 300`（測完改回 `1`）
    - 拿東西：`/give @s kaleidoscope_harvest:<物品ID>`
    - 找生物群系：`/locate biome flower_forest`、`/locate biome bamboo_jungle`
    - 找村莊：`/locate structure village`
    - 時間快轉：`/time add 24000`（醃漬缸計時用，第 8.2 節要確認快轉算不算數）
