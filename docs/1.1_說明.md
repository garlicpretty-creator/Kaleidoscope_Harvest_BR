## 水生型態

- 資料：`data/crops.js` 的 `form: "aquatic"`，野外 `wild.water: true`（validate 檢查兩者一定同時出現）。
- 方塊：`minecraft:liquid_detection`（`can_contain_liquid: true`），可以泡在水裡；放置條件是廚房的水田（有 `kaleidoscope_cookery:farmland` 標籤的方塊），或泥巴、黏土、泥土、草地、沙子上。**原版耕地不行**。
- 生長（`growth/environment.js` 的 `hasWater`）：底下是水田，或方塊本身泡在水裡（`block.isWaterlogged`）且底下是上面那幾種土。沒水時和種錯氣候一樣：停止生長、葉子發灰（共用 `off_climate` 狀態）。
- 採收：有 `pick` 的（茭白筍、空心菜）點它採收、退回 `harvestResetAge`；蓮藕一次性，打下收成。
- 野外：單一方塊地物的 `may_replace` 是水，底下要是泥巴等土；搜尋從地表往下找，所以會長在淺水裡。

**實機要確認的**：種子對著水底點下去時，`block_placer` 是否真的把作物放進水裡並變成含水；世界生成放進水裡的方塊是否含水。企劃書的退路仍然成立：不行就只能種在廚房水田。

## 對外 API

仍是 API 1：

- `crops` 的 `form` 多了 `aquatic`；文件加註「看不懂的 `form` 請當成 `once`」。
- 新 capability `catalog_foods`：`kind: "foods"` 回傳 `{id, hunger, saturation, placeable, container?}`。
- `api_ready.version` 是 `1.1.0`。

## 手冊

- 新型態「水生作物」的說明，加上一次性或可重複採收的第二行；野外的說明會寫「淺水裡」。
- 榨汁機多一行牛奶的說明；果木木板、蓮蓬、玉米葉都有自己的條目。
- 新的生物群系名稱：河邊、紅樹林沼澤、草甸、樺木森林。
- 簡中：補上「蓮莲、筍笋、楊杨、餡馅、餞饯、淺浅、樺桦、鋸锯」。

## 版本

`data/version.js`、兩個 manifest（header、模組、互相的相依）、`package.json` 都是 1.1.0，UUID 不變；沒有改任何既有 ID，1.0 的世界直接升級。

## 測試

`npm test` 新增 13 項（共 94 項），模擬的 `Block` 多了 `isWaterlogged`：

- 1.1 的作物、果樹數量；蓮藕在水中長大、成熟打下有蓮蓬；沒水停止並變灰，加水後恢復；原版耕地、石頭上不長；茭白筍、空心菜採收後退回。
- 水生方塊可含水、放置條件、種子、野外地物放進水裡。
- 苦瓜上竹藤架、紅豆收成、花椒灌木採收；玉米多掉玉米葉。
- 榨汁機加牛奶：還空桶、奶油色、只能一桶、空手拿回牛奶桶、木瓜不參與綜合果汁。
- 果木木板的標籤與配方；白米料理用廚房的米、蒜蓉茄子先合成再蒸。
- 樂牧玉米葉的 `fallback`；`catalog_foods`；草本、樂牧、酒館的新資料。
- 舊測試跟著更新：可放置 34 樣、`catalog` 的 kind 多了 `foods`、酒館三種酒；`wild_garlic_` 是 `wild_garlic_chives_` 的開頭，野生規則改成依生物群系逐一比對；`star_fruit_leaves` 不再被當成舊名稱 `<樹>_fruit_leaves`。
