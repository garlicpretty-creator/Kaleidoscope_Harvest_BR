# 1.3 說明：圖示重畫

1.3 只更新美術：沒有新物品、ID、配方或玩法改動，1.2 的世界直接升級。版本號仍只寫在 `packs/BP/scripts/data/version.js`。

```
npm run validate   # 版本號、貼圖與 PBR 都要一致
npm test           # 94 項
npm run build      # dist/Kaleidoscope-Harvest-v1.3.0.mcaddon
```

## 怎麼挑出要重畫的

把 244 張物品圖示排成總表逐張看，再用像素差距（輪廓＋顏色）算出彼此最像的組合，挑出兩種：

- **太像**：在 16×16 分不出來的，例如同一個褐碗裝的菜、同一個橘色瓶子的果汁、同一個白杯的茶、黃色圓餅狀的蛋料理。
- **不像實物**：例如荔枝像櫻桃、陳皮像整顆橘子、芒果是圓球、木瓜像甜甜圈、小黃瓜像豌豆莢、鳳梨酥與紅豆餅形狀不對、黃豆與蓮子是一團。

一共重畫 103 張，分四輪（對照圖在 `art/previews/`）：

| 輪 | 張數 | 內容 | 對照圖 |
| --- | --- | --- | --- |
| 1 | 25 | 蛋料理、褐碗菜、粉類、荔枝凍、豆腐 | `icons_1.3_dishes_powders.png` |
| 2 | 57 | 果汁、茶、湯鍋、雞肉料理、糕餅、生食材 | `icons_1.3_round2.png` |
| 3 | 17 | 陳皮、柿餅、芒果、木瓜、小黃瓜、四種茶等 | `icons_1.3_round3.png` |
| 4 | 4 | 黃豆、黑胡椒粒、蓮子、薑絲 | `icons_1.3_round4.png` |

做法：每樣在 `tools/art/icon_prompts.json` 寫清楚容器、主色與形狀，用 Retro Diffusion（`rd_plus__mc_item`，16×16）生 4 張候選挑一張，`art/icons/<id>.png` 由 `rd_icons.py apply` 進包，`pbr_maps.py` 補 `_normal`／`_mer`。檔名、ID 都不變。

## 沒改的

- 葉子方塊與種子的圖示：由程式依遊戲內貼圖產生；葉子彼此相像是因為遊戲內貼圖相像，要和遊戲內貼圖一起改。真實的種子本來就相像。
- 蓮藕、鳳梨冠芽、烤茭白筍：候選都沒有比原圖好，保留原圖。
- 作物、果樹與 3D 模型這版沒有變動。
